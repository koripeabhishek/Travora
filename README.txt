TRAVEL MORE, SPEND SMARTER — WEBSITE

Files:
- index.html
- styles.css
- script.js

Run locally:
1. Keep all three files in the same folder.
2. Double-click index.html.
3. It will open in Chrome.

Publish online:
- Upload these three files to a static hosting service such as GitHub Pages, Netlify, or Vercel.
- After deployment, you can connect a custom domain such as your chosen .com domain.

This is a frontend demo. The budget calculator uses sample planning estimates; it is not live booking or live pricing.
